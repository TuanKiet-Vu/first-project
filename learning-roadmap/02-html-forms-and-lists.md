# 02. HTML form + list (ul/li)

## Giải thích ngắn gọn
- Todo list cần: ô nhập (`input`) + nút (`button`) + danh sách (`ul`/`li`).

## Ví dụ: Input + Button
```html
<header>
  <input id="input" type="text" placeholder="Enter a task" />
  <button id="button">Add</button>
</header>
```

## Ví dụ: Danh sách `ul/li`
```html
<ul id="todo">
  <li>Learn HTML</li>
  <li>Build first todo</li>
</ul>
```

## Checklist
- Biết tạo `ul` và thêm `li` bên trong.
- Đặt `id` cho các phần tử quan trọng để JS lấy ra dễ dàng.
