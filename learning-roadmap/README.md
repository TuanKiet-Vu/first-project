# Lộ trình học HTML → CSS → JavaScript (làm web Todo List)

Mục tiêu: qua từng bước từ nền tảng HTML/CSS/JS, bạn sẽ tự làm được một **web todo-list cơ bản**.

## Thứ tự học hợp lý
1. HTML cơ bản (cấu trúc trang, thẻ phổ biến)
2. HTML form + list (input, button, `ul/li`)
3. CSS cơ bản (box model, layout)
4. CSS flex (layout header/todo item)
5. JavaScript DOM cơ bản (query, tạo/append phần tử)
6. JavaScript sự kiện (click)
7. Tách dữ liệu & render (mảng tasks + hàm render)
8. Hoàn thiện todo list (thêm + chuyển sang completed)
9. Debug (sai selector/id, lỗi logic)

## Cách dùng thư mục
- `01..09-*.md`: bài học ngắn gọn + ví dụ nhỏ.
- `examples/`: các snippet chạy được để bạn đối chiếu.
- `final-todo/`: dự án cuối cùng (todo list cơ bản).
