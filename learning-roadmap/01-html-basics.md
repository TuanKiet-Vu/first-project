# 01. HTML cơ bản

## Giải thích ngắn gọn
- HTML là khung xương của trang web.
- Bạn sẽ học cách dùng đúng các thẻ để tạo bố cục: `head`, `body`, `h1..h6`, `p`, `div`, `span`.

## Ví dụ
```html
<!doctype html>
<html>
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>Demo</title>
  </head>
  <body>
    <h1>My Todo</h1>
    <p>Trang của mình đang học HTML.</p>
    <div class="card">Nội dung sẽ nằm trong div</div>
  </body>
</html>
```

## Checklist
- Biết trang HTML tối thiểu gồm những gì.
- Biết thẻ nào dùng để tạo khối (`div`) và dòng chữ (`p/span`).
